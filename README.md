# איך להתחיל להתאמן לבד בחדר כושר: אתר הקורס

אתר סטטי (HTML/CSS/JS) בלי שרת ובלי עלויות, שמיועד לאחסון ב-GitHub Pages.

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | דף הבית |
| `course.html` | דשבורד הקורס: רשימת שיעורים, נגן ותיאור |
| `js/lessons.js` | **כל תוכן הקורס**: פרקים, שיעורים, מזהי YouTube, תיאורים |
| `js/home.js` | בראש הקובץ: **פרטי יצירת קשר** (WhatsApp, מייל, Instagram) |
| `js/progress.js` | שמירת התקדמות בדפדפן (localStorage) |
| `js/course.js` | הלוגיקה של דשבורד הקורס |
| `css/style.css` | עיצוב. הצבעים מוגדרים בראש הקובץ (`--red`, `--black`, `--white`) |
| `assets/` | תמונות (למשל תמונת מאמן) |

## הוספת סרטון

1. העלו את הסרטון ליוטיוב. אפשר במצב **לא רשום (Unlisted)**.
2. העתיקו את מזהה הסרטון מהקישור: `https://youtu.be/XXXXXXXXXXX`, כלומר החלק שמופיע אחרי הלוכסן.
3. ב-`js/lessons.js` הדביקו אותו בשדה `youtubeId` של השיעור, ועדכנו את `title`, `description` ו-`notes`.

> אל תשנו את ה-`id` של שיעור אחרי שהאתר עלה לאוויר, כי ההתקדמות של המשתמשים נשמרת לפיו.

## צפייה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן. הנגן של YouTube עובד בצורה הכי אמינה דרך שרת מקומי:

```
python -m http.server 8000
```

ואז לגלוש אל http://localhost:8000

## העלאה ל-GitHub Pages (כשתהיו מוכנים)

1. צרו repository חדש ב-GitHub והעלו אליו את כל הקבצים.
2. בהגדרות: **Settings → Pages → Source: Deploy from a branch**, ובחרו `main` ואת התיקייה `/ (root)`.
3. אחרי כדקה האתר יהיה זמין בכתובת `https://<username>.github.io/<repo>/`.
